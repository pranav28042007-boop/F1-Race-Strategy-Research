# F1 Race Strategy Analyzer – Research Repository

Research papers and datasets collected for the development of
an AI-Based Formula 1 Race Strategy Analyzer.

## Project

The project uses historical Formula 1 race data to analyze:

- Tire degradation
- Tire compound performance
- Pit-stop timing
- Race strategy
- Weather and track conditions
- Lap-time prediction
- AI-based strategy recommendations

## Datasets

### FastF1

Primary dataset used by the project.

Contains:

- Driver
- Team
- Lap number
- Stint
- Tire compound
- Tire life
- Lap time
- Track status
- Position
- Air temperature
- Track temperature
- Humidity
- Rainfall
- Wind speed

### Other Datasets

Additional datasets collected from published research
and public sources for comparison and experimentation.

## Machine Learning

The project investigates:

- Tire degradation modelling
- Strategy simulation
- Pit-stop optimization
