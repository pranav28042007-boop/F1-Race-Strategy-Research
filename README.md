# Formula 1 Research Datasets

Datasets used for the **AI-Based Formula 1 Race Strategy Analyzer** project.

The complete dataset collection can be accessed here:

https://drive.google.com/drive/folders/1gd9C81MjMuqXoCJkA8nuwjnHjeallTjX?usp=drive_link

The datasets contain Formula 1 race, lap, driver, tyre, pit-stop, qualifying, and championship information used for research and model development.
